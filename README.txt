الماهر الماسي V7.0 - Netlify
================================
هذا المجلد جاهز للنشر على Netlify.

قبل الاختبار أضف في Netlify > Project configuration > Environment variables:
SUPABASE_URL = Project URL من Supabase
SUPABASE_SERVICE_ROLE_KEY = service_role secret key من Supabase

تنبيه: لا تضع SUPABASE_SERVICE_ROLE_KEY داخل index.html ولا تشاركه مع العملاء.
بعد إضافة المتغيرات اعمل Deploy جديد لهذا المجلد.

V7.2: إزالة قسم إعداد الربط لأول مرة من واجهة دخول المطور؛ تبقى إعدادات الخادم في Netlify Environment Variables.

V7.3: إصلاح الاستعلام السحابي، timeout واضح، دعم GET/POST، وإضافة health function.

V7.5: صفحة رئيسية جديدة، حجز مباشر، حساب عميل مبدئي، حجوزاتي، المسافرون المحفوظون، حالات الحجز، وتنبيه أوضح للشروط. يتضمن إصلاحات V7.4 للطباعة.

V7.6 UI Refresh: تصميم أكثر فخامة وضغط المساحات + صفحة حجوزاتي للموظف. ملاحظة: صورة فوتوغرافية فعلية للكعبة لم تُضمّن بعد لتجنب الاعتماد على رابط خارجي؛ تم تجهيز Hero فاخر قابل لإضافة asset محلي لاحقاً.

V7.7: Hero محلي للكعبة وبرج الساعة، لوحة إدارة بأيقونات compact، جرس إشعارات للموظفين، وحفظ حقيقي لتغيير اسم مستخدم/جوال/كلمة مرور المدير العام من لوحة المطور.

V7.8.2: منع مسح مستخدمي الجهاز عند كون السحابة فارغة، إصلاح bootstrap لأول رفع، upsert آمن للمستخدمين، وعدم إعادة كلمات المرور للمتصفح، وتخزين كلمات المرور الجديدة بصيغة scrypt.
