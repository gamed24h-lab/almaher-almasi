إعدادات النظام العامة

حساب المدير العام

هذه البيانات لا يستطيع تعديلها إلا المطور. يتم حفظ التغيير بدل إعادة الحساب إلى admin / 1234 عند كل تشغيل.
إرسال OTP الحقيقي عبر SMS أو WhatsApp أو البريد يحتاج ربط النسخة بسيرفر ومزود رسائل. في ملف HTML المحلي يمكن اختبار التدفق فقط.

إدارة الإصدارات والتحديثات

البيانات التشغيلية مثل الحجوزات والفروع والرحلات تبقى في Supabase بشكل مستقل عن نسخة الواجهة.

مركز تحديث النظام بدون Deploy

بعد تثبيت V8 يمكن رفع ملف HTML للإصدار الجديد من هنا. يتم حفظه في Supabase وتفعيله على الأجهزة تلقائيًا عند فتح النظام أو تحديث الصفحة.
ارفع ملف index.html للإصدار الجديد. جرّبه أولًا على قناة Test ثم فعّله Stable.

ربط Supabase

أدخل API URL وPublishable Key من مشروع Supabase. لا تضع Service Role Key أو أي Secret Key داخل التطبيق.
يمكن لصق Project URL أو Data API URL، وسيتم ضبطه تلقائيًا.
