# Ticket printing / PDF policy

- Ticket printing must be isolated from the application tab.
- Supported outputs: A4, 80mm thermal, 58mm thermal.
- Saving as PDF uses the browser/OS print destination so the exact same isolated ticket layout is used for both printing and PDF across desktop and mobile browsers.
- A4 ticket output must be fitted to one physical page. The print engine measures the isolated ticket before printing and scales it down only when required.
- Thermal tickets use continuous-height paper and must not overflow the selected paper width.
