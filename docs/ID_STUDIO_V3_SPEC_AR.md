# ID Studio V3 — مواصفات الموديول

> حالة التنفيذ: تأسيس معزول على فرع `feature/id-studio-v3`. لا يتم دمجه أو نشره على Stable قبل اختبار Test واعتماد المستخدم.

## المبدأ
- ID Studio موديول مستقل بصلاحياته عن Employees.
- صلاحية إدارة الموظفين لا تمنح أي صلاحية تلقائية على ID Studio.
- البطاقة يمكن أن ترتبط بموظف موجود، أو تكون مستقلة تمامًا بدون إنشاء مستخدم/موظف في النظام.
- الربط بالموظف اختياري (`linked_employee_id` nullable).

## أنماط البطاقة والطباعة
1. **Full ID / وجه واحد:** جميع البيانات المطلوبة على وجه واحد.
2. **Front & Back / وجهان:** بيانات مختصرة وأنيقة أمامًا، والبيانات الإضافية وQR والتعليمات خلفًا.
3. الطباعة: وجه واحد كامل / أمامي فقط / خلفي فقط / الوجهين / طباعة جماعية.
4. مقاس CR80 الحقيقي: 85.60 × 53.98 مم، مع معايرة Offset لكل طابعة.

## القوالب
- Makkah Luxury — مستوحى من القالب الأبيض/الأزرق/الذهبي المعتمد.
- Executive Side — مستوحى من القالب ذي الشريط الكحلي الجانبي.
- Clean Formal.
- Royal Dark.
- Minimal Corporate.
- كل قالب له Thumbnail وVersion مستقل، ونسخة Full ونسخة Front/Back.

## البيانات والهوية
- الاسم عربي/إنجليزي.
- ترجمة تلقائية للمسمى والقسم، وTransliteration للاسم، مع Auto Translate ON/OFF وتعديل يدوي.
- رقم بطاقة تلقائي متسلسل مثل `MA-001` مع منع التكرار وإمكانية سياسة Prefix حسب النوع.
- QR آمن يولد تلقائيًا من Token غير قابل للتخمين، وليس من رقم الموظف وحده.
- أنواع حامل البطاقة: موظف داخلي، موسمي، متعاون، سائق، مشرف، زائر، أخرى.
- تاريخ إصدار/انتهاء، حالة البطاقة، الفرع المالك، الموسم، الترخيص، الاعتماد.

## دورة حياة البطاقة
- Draft
- Pending Approval
- Active
- Suspended
- Expired
- Lost
- Revoked
- Reissued

بعد الاعتماد يمكن قفل الحقول الأساسية؛ التغيير الجوهري يتم عبر فتح بصلاحية خاصة أو إعادة إصدار. إعادة الإصدار تحتفظ بالسجل السابق وتبطل QR/Token القديم.

## التحقق والخصوصية
- صفحة QR العامة تعرض الحد الأدنى فقط: الاسم، الصورة عند السماح، المسمى، الشركة، حالة البطاقة، صلاحيتها.
- لا تعرض جوالًا أو هوية وطنية أو بيانات حساسة.
- Token عشوائي وقابل للإبطال عند الفقد/الإلغاء/إعادة الإصدار.

## الإدارة
- Dashboard: فعال، مسودة، بانتظار الاعتماد، موقوف، منتهي، قرب الانتهاء.
- بحث وأرشيف كامل.
- Audit Log للتغييرات والاعتماد والطباعة والتصدير والإلغاء وإعادة الإصدار.
- Print Log بعدد النسخ والمستخدم والتوقيت.
- Import CSV/Excel.
- Duplicate Card لتسريع إصدار بطاقات متشابهة.
- Quick Issue لبطاقة مؤقتة بأقل بيانات ثم استكمالها لاحقًا.
- منع التكرار الذكي.
